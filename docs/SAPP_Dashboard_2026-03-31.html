Performance Attribution — Brinson-Fachler

Tham chiếu: CFA L3 Portfolio Performance Evaluation • Brinson, Hood & Beebower (1986)
Cần ít nhất 2 kỳ snapshot để tính Brinson-Fachler. Hiện chỉ có Q1.2026 baseline. Em build template + công thức sẵn, sẽ điền số khi có T04 hoặc Q2.2026.

Decomposition công thức Brinson-Fachler

Total Active Return = Σᵢ (wᵢᴾ − wᵢᴮ) × (Rᵢᴮ − Rᴮ)  ←  Allocation Effect
                           + Σᵢ wᵢᴮ × (Rᵢᴾ − Rᵢᴮ)  ←  Selection Effect
                           + Σᵢ (wᵢᴾ − wᵢᴮ) × (Rᵢᴾ − Rᵢᴮ)  ←  Interaction
w = weight, R = return, P = portfolio, B = benchmark, i = asset class
